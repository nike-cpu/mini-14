mini-14 使用指南

版本 v1.1 · 本地离线 AI 助手 · 返回首页

一、准备

需要 Windows 10/11、约 2 GB 磁盘空间（不含知识库），以及两个 GGUF 模型文件：

用途模型
对话qwen2.5-1.5b-instruct-q4_k_m.gguf
向量检索bge-m3-Q4_K_M.gguf

把模型放进 models\，把 仓库 克隆或解压到 D:\mini-14，再放入 runtime\ 里的 llama.cpp 与 node（仓库 README 有说明）。

二、数据库：可选下载

首次双击 mini-14 启动时，如果知识库为空，会弹出三选一菜单：

  1. 下载 demo 数据库（45 MB，Release 附件，含公版书 / 政府文件 / Apache 语料）
  2. 导入本地 zip（自己打包的库）
  3. 跳过——只用空库聊天，稍后随时可以再下载
:: 也可以手动执行
powershell -File tools\download-kb.ps1 -Zip D:\下载\mini14-kb.zip

导入后会自动重建分片索引；打开聊天页只需加载 2.5 KB 的 manifest，首屏约 0.2 秒。

三、日常使用

1. 对话

双击桌面图标后浏览器打开 http://127.0.0.1:18014/。左侧可切换：

  • 子供向 / 成人向：温柔简单 vs 傲娇嘴硬，两个模式都称呼你「小用户」
  • 知识库检索：关闭后就是纯聊天，不查资料
  • 联网搜索：开启后回答前先搜 6 条网络结果，标注为「网络」资料
  • 深色 / 浅色、简 / 繁、正文颜色

2. 加资料

  • 资料库页面 →「＋ 导入资料」选文件（txt/md/html/csv）
  • 或把网页/文本丢进 inbox\ →「📥 收件箱」
  • 或 node tools\import_jsonl.mjs 你的资料.jsonl 主题名

四、常见问题

导入没反应 / 提示连不上

导入依赖 18018 端口的小服务。双击 修复导入.cmd 一键重启；还不行就重开 App，启动脚本会自动校验。

回答很慢

首次提问要加载模型；之后一般 1 秒内。重复问同一个问题会命中缓存（约 0.2 秒）。

问知识库里的东西却回答「资料里没提到」

说明检索相似度没到阈值。换个说法、把关键词说全，或把「参考资料条数」调大。

能完全断网用吗

能。默认所有请求只发往 127.0.0.1；只有你主动打开「联网搜索」才会把查询词发给搜索引擎。
